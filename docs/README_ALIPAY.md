# 支付宝支付配置说明

本文档介绍了如何配置支付宝支付功能，以便在系统中正常使用VIP购买功能。

## 1. 获取支付宝支付凭证

### 1.1 注册支付宝开放平台账号
1. 访问 [支付宝开放平台](https://open.alipay.com/)
2. 注册并完成企业认证（个人开发者也可以申请，但部分功能受限）

### 1.2 创建应用
1. 登录支付宝开放平台控制台
2. 进入「控制台」->「应用管理」->「网页&移动应用」
3. 点击「创建应用」
4. 填写应用信息并提交审核

### 1.3 配置支付产品
1. 在应用详情页，找到「功能列表」
2. 添加「电脑网站支付」或「手机网站支付」产品
3. 提交审核并通过

## 2. 生成密钥对

### 2.1 生成商户密钥对
使用OpenSSL或其他工具生成RSA密钥对：

```bash
# 生成私钥
openssl genrsa -out app_private_key.pem 2048

# 从私钥导出公钥
openssl rsa -in app_private_key.pem -pubout -out alipay_public_key.pem
```

### 2.2 上传公钥到支付宝
1. 在支付宝开放平台的应用详情页找到「接口加签方式」
2. 点击「设置/查看」
3. 选择「公钥」方式（推荐使用RSA2）
4. 将生成的公钥内容（去除首尾标识和换行符后）粘贴到输入框
5. 保存设置

### 2.3 保存密钥文件
将密钥文件放置在项目目录中的 `keys/alipay/` 文件夹下：
- `app_private_key.pem`: 商户私钥（必须保密）
- `alipay_public_key.pem`: 支付宝公钥（从支付宝平台获取）

## 3. 配置环境变量

在 `.env` 文件中配置以下参数：

```env
# 支付宝配置
ALIPAY_APPID=your_alipay_app_id              # 支付宝应用ID
ALIPAY_DEBUG=True                            # 是否使用沙箱环境
ALIPAY_RETURN_URL=http://localhost:5000/payment/success   # 同步回调地址
ALIPAY_NOTIFY_URL=http://localhost:5000/api/payment/alipay/notify  # 异步回调地址
```

## 4. 沙箱环境测试

### 4.1 启用沙箱模式
将 `ALIPAY_DEBUG` 设置为 `True`，并在支付宝开放平台开启沙箱环境。

### 4.2 获取沙箱账号
1. 在支付宝开放平台进入「研发服务」->「沙箱应用」
2. 使用系统提供的买家账号进行测试支付

## 5. 生产环境部署

### 5.1 修改配置
1. 将 `ALIPAY_DEBUG` 设置为 `False`
2. 更新回调地址为生产环境域名
3. 确保服务器网络可以访问支付宝接口

### 5.2 安全注意事项
1. 保护好私钥文件，不要将其提交到代码仓库
2. 确保回调接口的安全性，防止恶意请求
3. 记录支付日志便于排查问题

## 6. 常见问题

### 6.1 支付宝回调验证失败
- 检查公钥是否正确配置
- 确认使用的签名算法（RSA/RSA2）
- 验证服务器时间是否准确

### 6.2 支付成功但系统未更新状态
- 检查异步回调接口是否正常工作
- 查看服务器日志确认回调是否收到
- 确认数据库连接和事务处理是否正常
